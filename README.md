## 🚀 Live Features & Interactive MVPs

This website includes 4 live functional simulators:
1. **Interactive Expense & Vault Simulator**: Test 1-tap quick spends, manual debit/credit entries, real-time balance computation, and ledger management.
2. **Indian Bank SMS & UPI Parser Engine**: Live regex and NLP pattern extractor testing sample SMS messages from HDFC, SBI, ICICI, Axis Bank, and Paytm UPI with 98%+ confidence.
3. **Bharat Hisab-Kitab (Khata Udhar)**: Real-time lending & borrowing book with 1-tap simulated WhatsApp UPI reminder dispatch.
4. **50/30/20 Budget & Daily Safe-Spend Calculator**: Interactive slider calculating needs, wants, savings, and daily maximum safe expenditure.

## ☁️ Deploy on Render (Free Tier)

This website is configured for immediate 1-click deployment on Render free tier:

1. Link this repository (`https://github.com/SarveshJoshi242/ExpenseTrackerWebsite`) to Render.
2. Render detects `render.yaml` and deploys as a **Static Site** on the Free Tier with global CDN and automated SSL!

## 🛠️ Local Development

To run this website locally:
```bash
git clone https://github.com/SarveshJoshi242/ExpenseTrackerWebsite.git
cd ExpenseTrackerWebsite
npx serve . -l 3000
```
Open `http://localhost:3000` in any web browser.
